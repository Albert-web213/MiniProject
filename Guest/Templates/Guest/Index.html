About Our AI Building Design System

Our AI-Based 2D Conceptual Building Design and Cost Estimation System is developed to simplify early-stage residential planning. The system automatically generates structured 2D floor plans based on user inputs and provides approximate construction cost estimation.

By integrating intelligent layout generation, material recommendations, and a web-based interface built using Python and Django, the platform reduces manual drafting effort and supports faster, data-driven decision-making.
